Every crafting table gets a new tab listing what that table can craft, is sold out in the store you picked, and you haven't queued yet.

Português abaixo.

The whole mod is one line

MISSING = (what THIS table crafts)
        ∩ (SELL offers with 0 stock in the chosen store)
        − (what is already queued on THIS table)

Press "Next store" until you land on the shop you want. That shop is then pinned to that table — saved by name, so it survives a new shop appearing, an old one disappearing, and a server restart. From then on you just open the tab: the list is already there.

⚠ Install this mod LAST, after every mod that adds a crafting table. The table list is generated by scanning your server, so it only finds the tables that are already there — install it first and those tables get no tab. Nothing breaks and nothing warns you. See Install.

Why it exists

You keep a shop. Something sells out. The bell rings — and then you have to remember which table makes it, walk there, and find it in a list of 200 recipes. This tab answers that at the table itself: what should I be making right now?

Nothing to tick off

Queue the item on the table and it is gone from the list — because the mod reads CraftingComponent.WorkOrders, the table's own queue. Cancel the order and it comes back.

A mark the player has to make by hand is a mark the player forgets to make. Here, the thing that marks it is the act of queuing, which they were going to do anyway.

Reads state, not events. The list comes from sell offers with Stack.Quantity == 0, not from catching the sold-out moment. So it stays correct across server restarts, and after an item sells out while you were offline.

Install

Unzip into your server folder so that it merges with Mods/:

Mods/UserCode/BBCBrasil/ForaDeEstoque/ForaDeEstoque.cs
Mods/UserCode/BBCBrasil/ForaDeEstoque/ForaDeEstoqueMesas.cs
Mods/Translations/ForaDeEstoque.csv

Restart the server. No config file, no DLL, nothing to enable. Uninstall: delete the folder and restart — nothing is written to the world.

Order matters. The table list is generated by scanning your server, not written by hand, so it can only find the tables that exist at that moment. Install this mod after Mixology, IceCream, or any other mod that brings a crafting table — otherwise those tables come out with no tab, silently. Added a table mod later? Nothing to reinstall: run python3 instalar.py again and restart.

No override, no Harmony

This mod uses only the two techniques the Strange Loop Mods/UserCode/README.md puts first: a new : WorldObjectComponent class holding the tab, and [RequireComponent(...)] public partial class XObject {} to hang it on each table.

An .override.cs is a frozen copy of a game file: when Eco updates that file, your copy silently goes stale. A mod built on partial class survives updates.

What it does NOT do

  • Buy offers — a table crafts, it doesn't purchase. Sell offers only.
  • Tag offers — specific items only.
  • Ship modded tables in the package — the package covers the 69 base-game tables. Modded tables are supported, but their line is generated on your machine by the installer: shipping a reference to a mod you might not own would stop your server from compiling at all. That is also why install order matters.
  • Change anything. It only reads. It places no orders and touches no offer.

Credits — and how this mod was made

The idea, the design, the requirements and all the testing are by dartangn, who runs the BBC-Brasil Eco server and wanted an answer to a real problem: something sells out in the shop, and you have to remember which table makes it.

The code was written by AI, working from the official Strange Loop Games documentation — the Mods/UserCode/README.md that ships with the server, and the ModKit API reference at docs.play.eco. Every API used here was read from that reference or from code already running on the server; none of it was guessed.

That division matters, so it is stated plainly: a human decided what this should do and proved that it does it; an AI wrote the C#.

It was tested on a live server, not in theory. A test server running Eco 0.14.1.1 with 29 other mods, on a copy of the production world.
